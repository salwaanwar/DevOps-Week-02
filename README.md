# DevOps-Week 02

## Project Overview

This project was created as part of the DevOps Week 02 hands-on activity. The project demonstrates Git and GitHub version control, branching, commits, merging, and Pull Requests.

## Technologies Used

* Git
* GitHub
* HTML
* CSS
* JavaScript
* Docker

## Project Files

* `README.md` - Project documentation
* `index.html` - Main webpage
* `style.css` - Website styling
* `script.js` - JavaScript functionality
* `Dockerfile` - Docker configuration

## Git and GitHub Activities

* Created a GitHub repository named DevOps-Week 02.
* Added five project files.
* Created two feature branches.
* Made different changes in each branch.
* Merged the feature branches into the main branch.
* Created and merged a Pull Request.
* Updated the README.md file with project details.
* Pushed the final project to GitHub.

## Objective

The objective of this activity is to practice Git and GitHub workflows, including repository creation, branching, committing, Pull Requests, merging, and collaboration.
