# DevOps-Week 02

## Project Overview

This project was created as part of the DevOps Week 02 hands-on activity. The purpose of the project is to practice Git and GitHub concepts including repositories, commits, feature branches, merging, pull requests, and merge conflict resolution.

## Technologies Used

* Git
* GitHub
* HTML
* CSS
* JavaScript
* Docker

## Project Files

* `README.md` - Project documentation
* `index.html` - Main web page
* `style.css` - Styling for the web page
* `script.js` - JavaScript functionality
* `Dockerfile` - Docker configuration

## Git Activities Completed

1. Created a GitHub repository named **DevOps-Week 02**.
2. Added five project files.
3. Created two feature branches.
4. Made different changes in each feature branch.
5. Merged both feature branches into the main branch.
6. Created and merged a Pull Request.
7. Resolved a merge conflict.
8. Updated the README file with project details.
9. Pushed the final project to GitHub.

## Objective

The objective of this activity is to demonstrate practical understanding of Git version control and GitHub collaboration workflows.
